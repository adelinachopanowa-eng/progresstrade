# Поддръжка на сайта

Статичен сайт (GitHub Pages), без сървър и без build стъпка за деплой —
файловете в хранилището се публикуват директно. За да се избегне дублиране,
има два общи източника:

## 1. Хедър и футър — `partials/`

Навигацията и футърът се поддържат на **едно място**:

- `partials/header.html` — topbar + навигация (вкл. падащото меню „Услуги")
- `partials/footer.html` — футър + скриптовете в края

След промяна по тях изпълни:

```bash
python3 build/apply-partials.py
```

Скриптът ги инжектира във всички `.html` страници (начална, блог, вътрешни).

## 2. Стилове — `css/site.css`

`css/site.css` е общата дизайн-система (токени, бутони, навигация, футър,
карти, форма и т.н.). Всички страници го зареждат.
`blog/blog.css` съдържа **само** блог-специфичните стилове (статии, списък
постове) и разчита на `site.css` за общата рамка.

## Бележки

- Текстовете са на български. Не се измислят факти — липсващите данни са
  отбелязани с `[ЗА ПОПЪЛВАНЕ: ...]`.
- Цени не се показват като фиксирани извън началната — „индивидуална оферта
  след оглед".
- Формата за заявка ползва Formspree (`form.qform` → `action`). Преди пускане
  попълни реалния Formspree ID на мястото на `[ЗА ПОПЪЛВАНЕ: Formspree ID]`
  (регистрация с progresstradesofia@gmail.com). До тогава JS показва съобщение
  с телефона при неуспех.
