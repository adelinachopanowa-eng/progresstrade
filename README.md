# progresstrade.bg

Статичен сайт на Прогрестрейд — изкупуване на черни и цветни метали в
София. Без рамка и без сървър: чист HTML, CSS и малко JavaScript,
публикуван през GitHub Pages от клона `main`.

**Ако сте агент или разработчик, започнете от [CLAUDE.md](CLAUDE.md).**
Там са правилата за изграждане, за съдържанието и за проверката преди
публикуване.

## Какво къде е

| Папка | Какво съдържа |
|---|---|
| `partials/` | хедър и футър — единственото място, където се редактират |
| `css/`, `js/`, `fonts/` | стилове, скриптове и шрифтове на сайта |
| `images/` | снимките, в конвенцията, описана в CLAUDE.md |
| `build/` | скриптовете на изграждането |
| `blog/` | статиите |
| `social/` | дизайнът на постовете за Instagram, виж `social/README.md` |
| `chats/` | разговорите от първоначалния дизайн, само за история |

## Изграждане

```
sh build.sh
```

Подробностите и капаните са в CLAUDE.md.
